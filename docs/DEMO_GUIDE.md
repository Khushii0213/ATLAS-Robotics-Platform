# Five-minute demo guide

Reset simulation in Settings. Start in Command Center and introduce the Noida Distribution Center seed: ATLAS-03 is executing an outbound run, ATLAS-04 has a low-battery warning, and ATLAS-05 has degraded network conditions.

Show the tactical map and fleet table; select Teleoperation and issue a movement command to ATLAS-01, then emergency stop. In Mission Management create a delivery, run preflight, and start it. In Diagnostics inject `network_degradation` against a healthy robot, inspect the newly generated alert and log, then resolve it. Finish with deployment readiness and analytics, then explain that Reset makes the scenario repeatable.
